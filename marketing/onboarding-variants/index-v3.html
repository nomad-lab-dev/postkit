05Habit lock-in
Why this 5-step works —

1. Zero data entry. The user never types a topic name. AI auto-detects in step 2, user just confirms or renames in step 3. Friction stays low.
2. Three value moments back-to-back. Step 3 (sorted gallery) lands the classification wow. Step 4 (Smart Post) lands the AI wow. Step 5 (calendar + notif) lands the habit anchor.
3. Permission asked once, in context. Photo access requested on step 1 CTA — right before the scan starts, with on-device language. No surprise system prompts later.
4. Real photos throughout. All Unsplash mocks now (Italy/coffee/car/code/build). For shipping we swap with MarketingPhotoLibraryClient bundled assets, same plumbing as App Store screenshots.
5. Each step takes ~10-15 sec to read. Total perceived time matches the actual 90-sec scan, so the user doesn't feel they're waiting — they're discovering.
