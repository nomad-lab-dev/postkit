Same product. Three onboarding philosophies.

Round 4 (V4) gave you 3 visual personalities of the same flow. This round shifts the question: what transformation do we put center-stage? Each variant below is a different psychological angle on the same product. Mirror puts identity discovery at the center. Goldmine puts hidden value at the center. Demo First puts instant proof at the center. Step counts and flows differ — pick the angle that hits your target user hardest.

How to pick between Mirror / Goldmine / Demo First —

→ Mirror wins if your hypothesis is "users struggle with content strategy more than with execution." The user says "I don't know what to post about" → Mirror tells them. Great for Reddit / LinkedIn audiences searching for "personal brand clarity."

→ Goldmine wins if your hypothesis is "users need proof of ROI before they commit a habit." The user says "I'd post more if it was worth it" → Goldmine quantifies the upside. Great for Twitter founders, freelance audiences, anyone tracking time-as-money.

→ Demo First wins if your hypothesis is "users are tired of being asked to set up before seeing value." The user says "don't waste my time, show me" → Demo First proves it in 5 seconds. Great for ProductHunt / IndieHackers / "I won't grant photo access to random apps" crowd.

Reality check: you can A/B these in production. With React Native / SwiftUI, each variant is ~3 days of work. With the SwiftData seeder we already have, demo content is already wired up. Pick one to ship for v1.0 — the others become A/B candidates for the v0.3 paywall A/B you're prepping for App Store.
