PostKit · Onboarding rework · 5 variants

From dead to alive.

The current onboarding asks for input before showing value. These 5 variants reverse that: each one leverages a different psychological lever (reality check, future self, magic demo, hidden inventory, daily ritual) so the user feels the value before the work. Pick a direction — I'll wire it up in SwiftUI + Remotion next.
