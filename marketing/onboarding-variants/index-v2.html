Onboarding round 2 · Magic Moment forward

Show the magic. Use it everywhere.

Round 1 explored 5 angles. You picked "show me the sentence-to-post moment, use it more". These 3 new variants all keep the demo card as the hero — different framings, gradient backgrounds, no features we haven't built. The post photos in the mockups are real images (Unsplash) matching each example prompt so you feel the demo, not the wireframe.

Post First

Reverse · ship one post before setup
HookFirst action = ship a real post
VibeCool mint morning · clean + hopeful
RiskPhoto permission needed earlier
Psychology
Commitment via early win — instead of "setup → demo → magic", flip to "magic with YOUR photos → setup → habit". The user posts before they've invested anything, so cancellation costs feel high.
Copy voice
Conversational, present moment. "What did you do today?" — the question a friend asks. Not promotional.
Visual angle
Cool mint gradient. The whole UX feels like a thought-organizer, not a content tool. Hero element is a friendly input box.

Three things to notice across these 3 —

1. The "sentence → post" demo appears on welcome of F, screen 2 of G, and screen 2 of H (with the user's real prompt). It's the recurring visual motif so the brand promise becomes obvious.
2. All photos are Unsplash — they'll be swapped for real captures via the marketing-capture skill once we pick the variant. For now they sell the demo, not the wireframe.
3. Each variant has a distinct gradient personality on the welcome — brand-saturated (F), warm sunrise (G), cool mint (H). Easy to A/B in App Store screenshots later.
